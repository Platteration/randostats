How to export your messages
  • WhatsApp: open a chat → ⋮ → More → Export chat → Without media. One file per chat; import each one.
  • iMessage (Mac): import ~/Library/Messages/chat.db (grant Full Disk Access to your terminal or browser first). Everything comes in at once.
  • Android SMS: the "SMS Backup & Restore" app writes an XML file; import it directly.
  • Anything else: a CSV or JSON with columns contact, sender, direction, timestamp, text.

Everything stays on this machine in a local SQLite file. Nothing is uploaded anywhere.
