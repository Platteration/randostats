How to export your messages
  • WhatsApp: open a chat → ⋮ → More → Export chat → Without media. One file per chat; import each one.
  • iMessage (Mac): import ~/Library/Messages/chat.db (grant Full Disk Access to your terminal or browser first). Everything comes in at once.
  • Android SMS: the "SMS Backup & Restore" app writes an XML file; import it directly.
  • Telegram: Desktop app → Settings → Advanced → Export Telegram data, JSON format. Import result.json or the whole zip.
  • Instagram or Messenger: request your information, JSON format, then import the zip. Both live under messages/inbox.
  • Discord: Settings → Data & Privacy → Request all of my data, then import the zip. Discord only exports your messages, so nothing will show as received.
  • Anything else: a CSV or JSON with columns contact, sender, direction, timestamp, text.

Everything stays on this machine in a local SQLite file. Nothing is uploaded anywhere, and re-importing the same file changes nothing.
